# Spywheel

The goal of this project is to equip a remote-controlled car with a live video streaming system, allowing real-time monitoring from a web browser or other devices. A microcontroller (µC) with a camera module is mounted on the RC car, and a small HTTP server provides a live MJPEG stream. Users can view the stream and interact with the vehicle through simple controls, such as toggling LEDs or other actuators.

## Key Features

- Live video streaming: Provides real-time footage from the RC car’s perspective.
- Remote control interface: Includes simple controls, like LED toggling (might be expandable to motors/steering).
- Compact and modular design: The system is mounted in a custom 3D-printed case, ensuring secure attachment to the car.
- Expandable platform: Additional sensors or modules (e.g., MPU-6050, ultrasonic sensors) can be integrated for enhanced control and telemetry.
